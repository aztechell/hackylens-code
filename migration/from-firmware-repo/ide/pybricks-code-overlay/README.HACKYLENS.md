# HackyLens Code

This directory is generated by applying `ide/pybricks-code-overlay` to a
verified, pinned Pybricks Code source tree. Do not edit the generated copy;
edit the overlay instead.

```powershell
python tools/bootstrap_ide.py --offline
cd build\hackylens-code
node .yarn\releases\yarn-3.3.0.cjs install --immutable
node .yarn\releases\yarn-3.3.0.cjs test
node .yarn\releases\yarn-3.3.0.cjs typecheck
node .yarn\releases\yarn-3.3.0.cjs build
```

Web Serial requires a secure browser context. The development server at
`http://localhost:4173` qualifies; production hosting must use HTTPS.
